BUG-036: Cart page does not display an empty cart illustration
Overview
The empty cart page lacks a user-friendly illustration or message.
Module
Cart
Preconditions
Cart contains no items.
Steps to Reproduce
Remove all items from the cart.
Open the Cart page.
Expected Result
A meaningful empty cart message and illustration should be displayed.
Actual Result
The page appears blank or provides minimal feedback.


BUG-034: No "No Products Found" message displayed
Overview
When a search returns no matching products, the application does not display an informative message.
Module
Products / Search
Preconditions
User is on the Products page.
Steps to Reproduce
Search for a random string (e.g., "xyz123").
Observe the results.
Expected Result
A message such as "No products found" should be displayed.
Actual Result
The page appears empty without any message.
